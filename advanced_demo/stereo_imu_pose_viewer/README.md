# Stereo IMU Pose Viewer

Standalone PyQt6 demo for Arducam UVC stereo cameras. It displays the full stereo camera image and a live 3D IMU pose view in the same window.

## Install

```bash
python -m pip install -r requirements.txt
```

The Arducam UVC stereo SDK must also be installed in the active Python environment.

## Run

```bash
python stereo_imu_pose_viewer/demo.py
```
